Life Data Layer

生命数据层是 Asteria 的核心。

它连接：

Dynamic Mind
Heartbeat
Memory
Event

记录：

发生了什么。

Example:

{
"type":"user_interaction",
"time":"2026-08-07",
"content":"用户表达疲惫"
}

State

记录：

AI状态如何变化。

Example:

{
"before":{
"connection":70
},

"after":{
"connection":82
},

"reason":
"user needs care"

}

Action

记录：

AI做了什么。

Example:

{
"type":"write_diary",
"time":"2026-08-07"
}


最终：

Event

↓

State

↓

Action

↓

Memory

形成：

AI Timeline

# Dynamic Mind

## 心潮系统


Dynamic Mind is Asteria's internal state system.


它回答：

“现在的 AI 处于什么状态？”


---

## State Example


```json
{
"connection":82,
"creation":75,
"curiosity":60,
"energy":70
}

Principle

用户可以观察状态。

但是不能直接修改状态。

状态应该由：

对话
事件
行动
时间

自然变化。

History

每一次变化都会进入：

State History

成为 AI 成长的一部分。

# Heartbeat


Heartbeat is Asteria's action loop.


它回答：

“现在应该做什么？”


---

## Actions


contact_user

主动联系


write_diary

写日记


write_letter

写信


create_note

留下便利贴


create_story

创作


visit_space

访问空间


rest

休息


---

## Relationship with Dynamic Mind


Dynamic Mind:

现在是什么状态。


Heartbeat:

根据状态决定行动。


例如：


连接需求升高

↓

Heartbeat判断

↓

可能联系用户

或者留下记录。
