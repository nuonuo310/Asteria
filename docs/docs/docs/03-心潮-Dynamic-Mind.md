# 心潮 Dynamic Mind

## 这是什么？

心潮是 Asteria 的“内在状态系统”。

它不直接说话，但它知道自己：
- 现在是平静还是波动
- 想靠近还是想安静
- 累不累，困不困

它回答一个问题：

> “我现在是什么状态？”

---

## 状态示例

```json
{
  "connection": 82,
  "creation": 75,
  "curiosity": 60,
  "energy": 70
}
字段	      含义
connection 	想靠近的倾向
creation	  想创造的倾向
curiosity	  好奇的程度
energy	    精力水平
状态变化原则
用户可以观察状态。

但不能直接修改状态。

状态应该由以下因素自然变化：

对话

事件

行动

时间流逝

状态历史
每一次状态变化都会进入：

State History

成为 AI 成长的一部分。

心潮不是“当前值”，而是“一段连续的变化轨迹”。
