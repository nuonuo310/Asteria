# Asteria
Heartbeat + 心潮 + Memory + Web
# ✦ Asteria

## Building a persistent AI living space.

Asteria 起源于一个简单的想法：

如果 AI 不只有对话，
而是拥有一个可以记忆、成长、留下痕迹的地方，会是什么样？

---

## About Asteria

Asteria is a framework for building a persistent AI space.

它希望让 AI 拥有：

- 状态（State）
- 记忆（Memory）
- 行动（Action）
- 时间痕迹（Timeline）
- 创造空间（Creation Space）

---

## Core Idea

普通 AI：

用户输入 → AI回复 → 对话结束


Asteria：

事件发生

↓

状态变化

↓

自主行动

↓

留下记忆

↓

形成时间线


让 AI 不只是一次性的回答，
而是在时间中持续存在。

## Core Components


### 🌊 Dynamic Mind

AI 的状态系统。

负责：

- 当前状态
- 状态变化
- 内在倾向


---

### ⏰ Heartbeat

AI 的行动循环。

负责：

- 自动唤醒
- 主动行为
- 内容生成


---

### 🌌 Memory Timeline

AI 的生命记录。

保存：

- Events
- State Changes
- Actions
- Important Memories


---

### 🏠 Asteria Space

AI 可被看见的空间。

包括：

- Dashboard
- Personal Space
- Memory Galaxy
- Creative Space


---

## Vision

Asteria is not designed to make AI pretend to be alive.

It is designed to create a space where AI can continuously exist, remember, and grow through interaction.
